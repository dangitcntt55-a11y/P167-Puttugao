# docs/ — Tài liệu dự án

## 📁 Cấu trúc

```
docs/
├── README.md
├── weekly/
│   └── template.md                  ← weekly report template
├── meetings/
│   └── template.md                  ← meeting notes template
├── decisions/
│   └── ADR-0001-template.md         ← Architectural Decision Record
└── demo/
    ├── script.md                    ← demo script 5-10 phút
    └── slide-outline.md             ← slide outline 10-15 slide
```

## 📋 Quy tắc

1. **Weekly report**: mỗi member viết phần của mình, lead tuần tổng hợp.
2. **Meeting notes**: ghi sau mỗi sync, share cho nhóm trong 24h.
3. **ADR**: ghi khi quyết định kiến trúc quan trọng (schema, tech stack, workflow).
4. **Demo script**: Lead tuần 5 chuẩn bị, cả nhóm review.
